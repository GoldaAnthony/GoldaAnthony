GOLDA M BOOTSTRAP PORTFOLIO
===========================

1. Open this folder in VS Code.
2. Make sure the folder contains:
   - index.html
   - about.html
   - skills.html
   - projects.html
   - resume.html
   - contact.html
   - 404.html
   - css/style.css
   - js/main.js
   - images/profile.jpg
   - Golda_Anthony_CV.pdf
3. Open index.html with VS Code Live Server.
4. The layout uses Bootstrap 5 grid classes such as:
   - container
   - row
   - col-lg-7 / col-lg-5
   - col-md-6
   - g-4 / g-5
   - align-items-center
5. The uploaded profile photo is already connected as images/profile.jpg.
6. The uploaded CV is connected from the Resume page.
